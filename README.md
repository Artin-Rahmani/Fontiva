# Fontiva

**Fontiva** یک پروژه برای ساخت و تولید فونت‌های خاص و جذاب است که با تمرکز بر کیفیت، طراحی مناسب و تجربه کاربری مطلوب توسعه داده شده است.

## نصب و اجرا

### 1. دریافت سورس

ابتدا سورس پروژه را دریافت کرده و آن را در محیط موردنظر خود قرار دهید.

### 2. نصب کتابخانه‌ها

کتابخانه‌های موردنیاز پروژه در فایل `requirements.txt` قرار گرفته‌اند. برای نصب آن‌ها، دستور زیر را اجرا کنید:

```bash
pip install -r requirements.txt
```

پس از نصب موفقیت‌آمیز کتابخانه‌ها، می‌توانید به مرحله بعد بروید.

### 3. راه‌اندازی

فایل `app.py` را از پوشه `Fontiva` اجرا کرده و در صورت نیاز، مقادیر تنظیمات موردنظر خود را در آن وارد یا جایگزین کنید.

سپس پروژه را با دستور زیر اجرا کنید:

```bash
python app.py
```

در صورت اجرای موفقیت‌آمیز، برنامه آماده استفاده خواهد بود.

## استقرار روی هاست

پس از اطمینان از عملکرد صحیح پروژه در سیستم خود، می‌توانید آن را به هاست موردنظر منتقل کرده و با تنظیمات سرویس هاست، برنامه را به‌صورت دائمی اجرا کنید.

برای اجرای برنامه در محیط هاست، در صورت پشتیبانی سرویس شما، می‌توانید از دستور زیر استفاده کنید:

```bash
setup python app
```

سپس می‌توانید دامنه دلخواه خود را برای دسترسی به سایت تنظیم و متصل کنید.

پیش از قرار دادن پروژه روی هاست یا انتشار عمومی آن، حتماً مقادیر حساس مانند کلیدهای API، رمزهای عبور و سایر اطلاعات محرمانه را از کد حذف کرده و در محیط امن یا متغیرهای محیطی قرار دهید.
